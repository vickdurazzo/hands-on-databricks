# 🚲 Bike Sharing Analysis with Databricks

This notebook was developed as part of the **"Getting to Know Databricks"** course from Alura. It focuses on hands-on experience with Apache Spark using Databricks notebooks.

## 📘 Notebook: `final_project.ipynb`

### ✅ Key Concepts Practiced:

- Working with Spark DataFrames
- Explicit schema definition and inferSchema
- Reading CSV files from DBFS
- Creating temporary and permanent Spark SQL tables
- Querying data using SQL and DataFrame APIs
- Creating aggregations and frequency tables
- Filtering and creating new views

### 🔍 Project Summary:

Using a bike-sharing dataset, we explored rental patterns based on:
- Season
- Year
- Weather situation
- Workdays vs weekends


### 💾 Dataset

The dataset used comes from the [UCI Bike Sharing Dataset](https://archive.ics.uci.edu/ml/datasets/bike+sharing+dataset).
